# Architecture Amendment A6: Custom Evaluation Authoring Firewall

For C.Walts v0.4, all 285 custom query texts are private evaluation material
from creation and receive holdout-grade confidentiality. The 135
near/far/ambiguous records also carry allocation-implied future-holdout status.

Custom text must remain on the local machine. Cloud LLMs, hosted generation
APIs, ChatGPT, Codex transcript output, and retrieval or performance feedback
are prohibited during authoring. Gate 3 uses only an approved local model,
local owner review, and frozen policy/model/prompt/tooling identities. Gate 2
text is not a generation seed. Custom candidates remain ignored and pre-split;
Gate 4 owns formal split and sealing. After acceptance, custom content cannot
justify corpus, retrieval, threshold, or calibration changes.
